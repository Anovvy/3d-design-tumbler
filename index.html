    Cara Kirim Desain 3D & Spec ke Perajut

    Panduan praktis agar perajut bisa memutar model 3D sendiri dan membaca detail dimensi, benang, serta BOM dengan akurat.

    1. Ekspor Foto Referensi Multi-Sudut (PNG)

      Gunakan preset kamera Depan, Belakang, Kanan, dan Detail Leher (dengan Garis Dimensi aktif), lalu klik Export PNG pada setiap sudut untuk dikirim langsung lewat WhatsApp sebagai referensi visual cepat.

    2. Kirim Folder Proyek Web 3D Interaktif

      Zip seluruh folder proyek (termasuk index.html, folder src/, dan ref/) atau unggah ke hosting statis (GitHub Pages / Netlify Drop / Vercel). Perajut cukup membuka link atau menjalankan server lokal (npx serve / python -m http.server) untuk memutar model 360° dari HP maupun laptop.

    3. Sertakan Panduan Cetak / PDF & Daftar BOM Shopee

      Cetak halaman panduan pola atau ekspor ke PDF (Ctrl+P → Save as PDF) bersama daftar komponen dari tombol BOM & Link Shopee agar perajut memesan Silicone Neck Ring wide-mouth (Ø 5.5–6.0 cm) dan paracord 4 mm yang tepat.

    Catatan Penting untuk Perajut Kait tali 30 cm & 100 cm dipasang langsung ke lubang kuping Silicone Neck Ring (4 titik ikat benang Polycherry).
